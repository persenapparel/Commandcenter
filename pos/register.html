Checking active seasonal campaign…

Epson automatic receipts: a paid cash sale queues a receipt to the authorized Epson Windows service. The laptop must be awake, online and running that service. The browser cannot detect physical printer readiness. A manual backup below can create a duplicate receipt.

How Epson automatic receipts work (Windows laptop)
  1. Install the Epson TM-T20IV Windows driver. Test a proper 80 mm thermal receipt roll and the automatic cutter.
  2. Install and start the separate signed-in Epson Node print service on your Windows laptop using its staging setup guide.
  3. Keep the laptop awake, online and connected to the printer. After a confirmed cash sale, the service claims a single receipt job and sends it directly to the Epson.
  4. Confirm the paper actually printed before handing it out. Windows accepting a job cannot guarantee a printed receipt.

The laptop back office displays the receipt and drawer queues. The old NELKO browser Print Station is disabled for this Epson staging build; it must not claim the same jobs.
