Automatic receipt printing

After a confirmed cash sale, Persen POS queues a receipt. This station checks every second and submits it to the printer configured in Chrome.

Not armed · printer not verified

Important: Browsers normally show a print dialog. Silent printing requires a separately configured, trusted Chrome kiosk-printing shortcut and correct default printer.

NELKO setup

One receipt per completed sale. Extra copies can be requested using a manual, verified reprint after checking what has printed. Receipts older than 24 hours remain in history but will not print automatically.

Select the matching size in the NELKO Windows print driver too. The PL70E has a manual tear-off edge, not an automatic cutter.

Physical printer check

This webpage cannot detect whether your NELKO is connected or whether paper came out. First print a test receipt using Chrome and verify the paper. The print station will not automatically send paid-sale receipts until you confirm this test.
